# 🎬 Forgotten Island

**Forgotten Island** is an animated adventure movie about two best friends named **Jo and Raissa**. They discover a mysterious portal that takes them to a magical island called **Nakali**, where they encounter different magical and mythological creatures.

### 🌟 Why I Like This Movie

I like this movie because it shows the importance of **friendship, memories, and staying connected with the people we care about**. It also introduces Filipino folklore and mythical creatures in an exciting and entertaining way.

### ❤️ My Favorite Thing About It

For me, *Forgotten Island* is a memorable movie because it combines **adventure, humor, and meaningful lessons about friendship**.
